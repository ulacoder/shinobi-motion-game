# Путь печатей

Веб-игра для кейса **«Motion: камера вместо джойстика»** (Admit Hackathon 2026, направление **«Игра»**).

Складывай печати руками перед обычной веб-камерой, собирай их в цепочки-техники и пройди сюжет:
подпешки → пешки → главный злодей Кагэро, владыка клана Затмения.
Клавиатура и мышь не нужны: даже меню переключается жестами. Всё распознавание идёт прямо в браузере.

**Команда:** _Team Jacket_
**Деплой:** https://shinobi-motion.vercel.app
**Код:** https://github.com/ulacoder/shinobi-mmotion

---

## Для жюри: за 3 минуты

1. Откройте https://shinobi-motion.vercel.app в Chrome или Edge на ноутбуке с веб-камерой и разрешите доступ к камере.
   Пока читаете заставку, в фоне грузится распознавание рук (≈20 МБ, процент виден под кнопкой).
2. В меню выберите **«Быстрый бой с боссом»**: жестом «Птица» (обе руки, большой палец и мизинец в стороны),
   мышкой или клавишей `3`. Это один бой с главным злодеем и экран итогов, 2–3 минуты.
3. Полный сюжет — пункт «Сюжет» (5 боёв, 6–10 минут). Обучение печатям — «Обучение в додзё».
4. Меню, итоги и диалоги можно листать и мышкой/клавишами (`1`–`3`, пробел), сам бой — только жестами.
   Клавиша `D` показывает отладку распознавания.

## Как играть

1. Открой ссылку и нажми «Включить камеру» (браузер спросит разрешение один раз).
2. Сядь так, чтобы руки у лица были в кадре.
3. В меню раскрой обе ладони и держи секунду — начнётся обучение в додзё. Покажешь Тигра — сразу в сюжет.
4. В бою складывай цепочки печатей, защищайся щитом, накопи чакру и добей врага нарисованным в воздухе кругом.
5. В конце — очки, статистика, твои самые частые ошибки и таблица рекордов.

## Сюжет

Клан Затмения напал на деревню у Ветряного перевала. Навстречу идут трое друзей — **Улагат** (главный герой, им играешь ты),
**Таир** и **Данияр**. У каждого свой портрет, причёска и цвет шарфа. Реплики озвучены самой командой (см. «Озвучка»).

| Этап | Враги | Что меняется |
|---|---|---|
| 1 · Подпешки | Мукадэ, Ябу | мало здоровья, медленные удары — можно освоиться |
| 2 · Пешки | Близнецы Пепла: Хайко и Сумико | бьют сильнее и чаще — без щита не обойтись |
| 3 · Главный злодей | Кагэро | много здоровья; на половине здоровья впадает в ярость и заряжает удары быстрее |

Между боями — сцены-диалоги в стиле манги (перелистываются жестом «раскрытые ладони» или сами).
Здоровье героя переносится между боями, перед этапами он немного восстанавливается.

## Аниме-подача

Все персонажи, фоны и эффекты — свои, нарисованы кодом на canvas: кат-ин с портретом героя и названием техники,
линии скорости, «кадр удара» (негатив на долю секунды), японские звуковые надписи (ドン!, バチバチッ!, ゴゴゴ…),
облако дыма при поражении врага, свой фон на каждом этапе. Молния — «грозовой удар»: сначала над врагом собирается туча
и появляется прицельный круг, затем бьют ветвистые молнии со вспышкой. Для каждой печати есть иконка рук, построенная прямо из её правил.

## Озвучка, музыка и звуки

- **Голоса.** Реплики озвучили сами участники команды — список в [`VOICES.md`](VOICES.md).
  Сырые записи прогоняются через `scripts/process-voices.py`: шумоподавление, обрезка тишины по краям
  и сокращение длинных пауз (порог считается от шума каждой записи), компрессия, выравнивание громкости до −15 LUFS
  и эффекты по персонажу: у героев — лёгкий «зал», выкрики техник — с эхом и усилением, сенсей — ниже и с реверберацией,
  Кагэро — сильно ниже, с «рычанием» и длинным эхом. Разметка «запись → реплика» лежит в `scripts/voices-map.json`.
  Пока звучит голос, музыка автоматически приглушается. Реплики без записи показываются текстом.
- **Музыка.** Своя, генерируется в браузере на лету: японский лад мияко-буси, кото, флейта сякухати, барабаны тайко и симэ, сямисэн.
  Спокойные треки для меню, додзё и сцен; в бою — эпичная музыка в духе трейлеров: ансамбль тайко, пульсирующий бас,
  аккорды-удары, хор, тарелки и нарастания перед каждой фразой. Музыка разгоняется по ходу боя: когда у врага меньше
  половины здоровья, добавляются хай-хэт и хор, в решающий момент — дробь барабанов.
- **Звуки места.** Ветер везде, птицы в лесу и на рассвете, река под мостом, гул и треск углей у затмения, сверчки ночью.
- **Звуки интерфейса.** Печатание текста в диалогах, шорох страницы, отсчёт перед боем с ударом барабана, выход врага,
  титры этапа с гонгом, щелчки при удержании жеста в меню, оглушение, готовый ультимейт, рёв босса, сердцебиение при низком здоровье.
- **Звуки.** По умолчанию реалистичные звуки синтезируются в браузере (шум, фильтры, реверберация): рёв пламени с треском,
  раскат грома, всплеск щита, удары. Любой звук можно заменить своим файлом: `public/sounds/<имя>.mp3`, имена —
  `seal, hint, cast, fire, lightning, shield, sphere, hit, hurt, blocked, charge, combo, smoke, win, lose, select`.

### Бамбуковые сундуки

После второй подпешки и после Близнецов Пепла на пути стоит бамбуковый сундук. Чтобы его открыть, нужно три раза
поднять ладонь и опустить её вниз — и внутри новый приём: сначала «Клинок ветра», потом ультимейт «Удар дракона».
Удар распознаётся своей логикой по скорости руки между кадрами (`src/chop.js`): ладонь должна быть раскрыта
(пальцы прямые), идти вниз быстрее ~1,5 высоты кадра в секунду и пройти заметный путь. Ошибки подсказываются:
«Смелее! Плавно опусти вниз», «Выше! Подними ладонь над головой», «Раскрой ладонь: не кулак», «Сверху вниз, а не вбок».
В быстром бою с боссом оба приёма открыты сразу.

Описание каждой техники видно в додзё и в кат-ине в момент применения.

### Твои печати на экране и трансформация

Каждая сложенная печать сохраняется как «снимок» твоих рук и появляется в цепочке карточкой-рисунком тушью.
Когда техника срабатывает, эти формы рук вылетают в кат-ин и превращаются в название техники (вспышка → иероглиф → приём).
В конце похода — галерея твоих лучших печатей.

### Комбо

Техники подряд (не дольше 7 секунд между ними) наращивают комбо: ×2 даёт +20% урона, ×3 — +40%, максимум ×2 к урону.
Пропущенный удар сбрасывает комбо. Особые связки дают дополнительный урон:

| Связка | Порядок | Бонус |
|---|---|---|
| Грозовое пламя | Молния → Огненный шар | +10 |
| Контрудар молнией | Водяной щит → Молния | +8 |
| Огненный вихрь | Огненный шар → Вихревая сфера | +12 |

Лучшее комбо и число особых связок добавляют очки в итоге.

Сила техники зависит от точности печатей: печать на пороге распознавания даёт 60% силы, идеальная — 100%.

## Режим «ошибка» (твист)

Каждая печать описана набором **понятных правил**, а не «чёрным ящиком»: какой палец прямой,
какой согнут, где руки относительно друг друга. Каждое правило даёт оценку от 0 до 1 и **свою подсказку**.
Поэтому игра знает, *что именно* не так, и говорит об этом голосом сенсея:

- **Пальцы:** «На левой руке: согни безымянный палец», «На правой руке: отставь большой палец в сторону».
  Неверный палец подсвечивается красным прямо на скелете руки.
- **Форма руки целиком:** если неверно сразу много пальцев — одна понятная подсказка: «Сожми правую руку в кулак».
- **Положение рук:** «Сведи руки ближе друг к другу», «Подними раскрытую ладонь над кулаком».
- **Направление:** «Направь указательный палец вверх».
- **Круг в воздухе** (свой алгоритм: подгонка окружности методом наименьших квадратов, угол обхода, разброс радиуса):
  «Круг не замкнут: доведи линию до места, где начал», «Круг вышел кривым или овальным…»,
  «Круг слишком маленький…», «Слишком быстро: рисуй круг плавно».
- **Порядок печатей:** «После печати „Тигр“ для техники „Огненный шар“ нужна „Змея“, а не „Дракон“»,
  «Цепочка оборвалась: между печатями не больше 4 секунд».
- **Тактика:** «Удар пропущен: когда под врагом растёт красная полоса, ставь щит (Собака → Дракон)».
- **Условия съёмки:** «Слишком темно…», «Правая рука уходит за край кадра (вправо)…»,
  «Руки слишком далеко: придвинься ближе», «Нужны обе руки: вторую камера не видит».
- **Слабая техника:** если печать засчитана, но неидеально, сенсей называет самое слабое место:
  «Огненный шар: сила 72%. Точнее: на левой руке: согни безымянный палец».

В додзё под каждой печатью виден разбор по каждому пальцу (✓/✗) и шкала совпадения.
В конце боя — список самых частых ошибок игрока с советами.

## Производительность

- Статичный фон этапа рисуется один раз в отдельный холст; враг перерисовывается ~20 раз в секунду в свой холст,
  а на сцену ставится одной картинкой. Частицы огня и туч — готовые спрайты вместо градиента на каждую частицу.
- Никаких `ctx.filter` и тяжёлых размытий: вспышки сделаны режимом «осветление».
- Качество подстраивается само: если кадры дольше ~24 мс, игра снижает разрешение холста и число частиц.
- Если распознавание рук на слабом ноутбуке занимает много времени, оно запускается реже, а графика остаётся плавной.
- DOM обновляется только при изменении значений; размер слоя камеры берётся из `ResizeObserver`.
- Отладка (`D`) показывает FPS, время распознавания и текущий уровень качества.

## Как это устроено

- **MediaPipe Hand Landmarker** (`@mediapipe/tasks-vision`) даёт 21 точку на каждую руку. Больше ничего готового не используется.
- **Своя логика распознавания** (`src/geometry.js`, `src/seals.js`):
  - сгиб пальца = сумма углов в трёх суставах по 3D-точкам;
  - отведение большого пальца = расстояние от кончика до основания указательного в «ладонях»;
  - правила печатей, мягкие оценки 0..1, взвешенная точность, порог засчитывания;
  - для двуручных печатей перебираются оба распределения ролей (кулак/ладонь) — неважно, какой рукой что делать;
  - сторона руки определяется по положению в зеркальном кадре, а не по ненадёжной «handedness» (работает и у левшей).
- **Стабилизация** (`src/detector.js`): печать нужно удержать ~0.4 с, повтор засчитывается только после «отпускания», точность сглаживается.
- **Круг в воздухе** (`src/air.js`): подгонка окружности (Kåsa), угол обхода, «круглость», размер, скорость.
- **Логика боя** (`src/battle.js`) отделена от камеры и отрисовки и покрыта тестами.
- **Графика и звук** без чужих картинок: всё рисуется на canvas (`src/fx.js`, `src/characters.js`), звуки синтезируются Web Audio (`src/audio.js`), своя озвучка подхватывается из `public/voices`.
- Рекорды и лучшая точность по каждой печати сохраняются в браузере.
- Вёрстка адаптирована под телефон (фронтальная камера, вертикальный экран).

## Запуск локально

Нужен **Node.js 20.19+** (или 22.12+).

```bash
npm install
npm run dev
```

Открой адрес из консоли (обычно http://localhost:5173) в Chrome, Edge или Safari и разреши доступ к камере.
Камера в браузере работает только на `localhost` или по `https://`.

`npm run dev` и `npm run build` сами копируют WASM MediaPipe в `public/wasm` и скачивают модель рук
в `public/models`. Если скачать модель не получилось, игра загрузит её из сети при запуске.

Другие команды:

```bash
npm test          # тесты распознавания и логики боя
npm run build     # сборка в dist/
npm run preview   # посмотреть сборку локально
```

**Отладка:** клавиша `D` (или `?debug` в адресе) показывает «сырые» значения по каждому пальцу и топ-3 печати —
удобно подстраивать пороги под свою камеру (`BEND_STRAIGHT`, `BEND_CURLED` в `src/geometry.js`,
`PASS_ACCURACY` в `src/seals.js`).

## Деплой

**Vercel:** Add New → Project → импортировать этот репозиторий → Deploy. Настройки уже лежат в `vercel.json`.

**Любой статический хостинг:** `npm run build` и выложить папку `dist/` (нужен HTTPS для камеры).

## Бонусы

- собственная логика распознавания жестов (правила по геометрии пальцев + свой распознаватель круга);
- быстрый режим «бой с боссом» для короткой проверки;
- таблица рекордов и лучшая точность по каждой печати;
- адаптация под камеру телефона;
- звук, озвучка командой и визуальные эффекты;
- комбо и особые связки техник, галерея твоих печатей.
